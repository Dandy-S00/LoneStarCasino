# LoneStarCasino

A Texas-themed casino lobby built from the LuckyWinnerPower React app. Players can create an account, log in, choose a game, and play directly inside the site.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Game outcomes in the current lobby are demo-credit gameplay and should be connected to a properly regulated backend before any real-money use.
